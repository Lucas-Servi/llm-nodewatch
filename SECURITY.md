# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities via email to **lucasservi@gmail.com**.

Do **not** file public GitHub issues for security bugs.

## What to include

- Description of the vulnerability
- Steps to reproduce
- Impact assessment (if known)

## Response

You can expect an initial response within 72 hours. We will work with you to understand and address the issue before any public disclosure.

## Supported Versions

Only the latest release is actively supported with security patches.
